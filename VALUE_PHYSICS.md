# Value Physics

The Value Physics Engine replaces popularity-based metrics with a physical-analogous framework for assessing knowledge impact.

## Metrics

- **Knowledge Energy**: The capacity of knowledge to drive behavior change or new discoveries.
- **Knowledge Momentum**: The rate at which knowledge is being applied and evolving across the system.
- **Knowledge Potential**: The latent value of knowledge that has high theoretical impact but low current activation.
- **Knowledge Entropy**: The degree of disorder or decay in a knowledge object (e.g., outdated information, lack of clear application).
- **Knowledge Activation**: A measure of current real-world application.
- **Knowledge Resonance**: The degree to which a piece of knowledge influences other nodes, clusters, or participants.
- **Knowledge Decay**: The natural loss of relevance or accuracy over time if not reinforced.
- **Knowledge Regeneration**: The process by which dormant or decaying knowledge is updated and brought back to relevance.

## Implementation
These values are recalculated dynamically based on system events, user feedback, and observed outcomes.
