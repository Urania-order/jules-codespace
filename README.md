# ECO Co-SMOS: A Knowledge Ecology Engine

ECO Co-SMOS (v0.8) is a living ecosystem where knowledge evolves through cooperation between humans and AI agents. It transitions away from the concept of a static "memory" towards a dynamic "ecology."

## Key Concepts

### Knowledge Lifecycle
Knowledge is treated as a living entity with states:
`Idea → Discussion → Recipe → Experiment → Practice → Behavior Change → Collective Experience → Improved Knowledge`

### Knowledge Ecology
The system manages the lifecycle, propagation, resonance, activation, dormancy, and evolution of knowledge.

### Value Physics
A new engine that evaluates knowledge based on long-term impact rather than popularity, using metrics like Energy, Momentum, Potential, Entropy, and Resonance.

### Human-AI Symbiosis
Humans provide meaning and value assessment, while AI provides exploration and connection. Neither replaces the other; value emerges from their cooperation.

### Attention Ecology
Attention is allocated based on usefulness and verified outcomes, helping valuable but under-discovered knowledge emerge.

### Behavioral Collaboration
Users collaborate based on cognitive styles and communication preferences. AI Translator Agents help reduce misunderstandings and explain intent.

### Epistemic Layers
Strict labeling of knowledge (Verified, Hypothesis, Counterfactual, Speculative, etc.) ensures clarity while allowing cross-category inspiration.

### Living Clusters
Knowledge clusters are living entities with health, activity, and evolutionary paths.

### Sovereignty & Federation
Designed for federation and distributed synchronization to resist centralized control of collective knowledge.

### Research Portals
A framework for collective sponsorship and transparent funding of experimental research.

## Getting Started

1.  **Initialize Database**: `PYTHONPATH=. python3 smos/core/init_db.py`
2.  **Run API**: `uvicorn smos.api.main:app --reload`
3.  **Run MCP Server**: `python3 smos/core/mcp_server.py`
